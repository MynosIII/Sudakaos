    Estado de las fuentes

    Por qué no hay Facebook, Instagram ni X

    Meta no ofrece una API abierta para buscar publicaciones o comentarios, y scrapear sus sitios viola sus términos. La API de X es paga. El monitor usa fuentes públicas y gratuitas: comentarios de YouTube (API oficial), notas de medios (Google News y RSS) y visitas a Wikipedia.
