    Estado de las fuentes

    Por qué no hay Facebook, Instagram ni X

    Meta no ofrece una API abierta para buscar publicaciones o comentarios de páginas y grupos, y scrapear sus sitios viola sus términos. La API de X es paga. El monitor usa fuentes públicas y gratuitas: comentarios de YouTube (API oficial), notas de medios regionales y nacionales (Google News y RSS directos) y OpenStreetMap para el mapa.
